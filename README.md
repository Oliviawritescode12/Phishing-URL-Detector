 Phishing-URL-Detector
 
An educational cybersecurity project for identifying potentially malicious URLs.

Overview

The Phishing URL Detector is a Python application that analyzes URLs for characteristics commonly associated with phishing attacks. The project helps users identify suspicious websites by checking for indicators such as insecure protocols, unusual domain structures, excessive URL length, IP addresses in place of domain names, and suspicious keywords.
This project was built to improve my understanding of phishing techniques, URL analysis, and defensive cybersecurity practices.

Features

Analyze URLs for phishing indicators.
Detect suspicious keywords.
Check whether HTTPS is used.
Identify IP addresses used instead of domain names.
Flag unusually long URLs.
Display a phishing risk assessment.
Explain why a URL is considered suspicious.
